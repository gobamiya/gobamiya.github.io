## Host Discovery

<https://nmap.org/book/host-discovery-strategies.html>

***

Host Discovery : 살아있는 호스트 확인

-sn 옵션 : Ping 스캔 (port 스캔 안함)

같은 네트워크 ARP Ping
다른 네트워크 ICMP Ping

Host Discovery 효과적인 방법 : ICMP Echo Requests
-sn -PE --disable-arp-ping

***

**네트워크 범위를 지정해서 스캔**
\$ sudo nmap 10.129.2.0/24 -sn -oA tnet | grep for | cut -d" " -f5

**스캔할 IP 파일 지정**
\$ sudo nmap -sn -oA tnet -iL hosts.lst | grep for | cut -d" "  -f5

**여러 IP 주소**
\$ sudo nmap -sn -oA tnet 10.129.2.18 10.129.2.19 | grep for | cut -d" " -f5

\$ sudo nmap -sn -oA tnet 10.129.2.18-20 | grep for | cut -d" " -f5

**단일 IP 스캔**
\$ sudo nmap 10.129.2.18 -sn -oA host

**ICMP Echo Requsets (-PE)**
$sudo nmap 10.129.2.18 -sn -oA host -PE --packet-trace$ sudo nmap 10.129.2.18 -sn -oA host -PE --reason

\[송수신 패킷 표시]
\--packet-trace

\[포트의 상태status 이유]
\--reason

**ICMP Echo Requests (-PE) / disable ARP Ping**
\$ sudo nmap 10.129.2.18 -sn -oA host -PE --packet-trace --disable-arp-ping

\[ICMP Ping을 통한 OS 식별 - TTL]

- Linux = 64
- Windows = 128
- Cisco = 256
