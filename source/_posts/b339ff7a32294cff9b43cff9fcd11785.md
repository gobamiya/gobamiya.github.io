## Discovering Open TCP Ports / open된 TCP 포트 찾기

| 실행 권한   | 기본 스캔 방식               |
| ------- | ---------------------- |
| Root 권한 | SYN Scan (-sS)         |
| 일반 사용자  | TCP Connect Scan (-sT) |

**옵션없을 때 기본 동작 상위 1000개**
\# nmap 10.129.2.28 // -sS : SYN 스캔으로 1000개 TCP 포트 스캔
\$ nmap 10.129.2.28 // -sT : TCP Connect 스캔

**TCP 포트 상위 10개 스캔**
\$ sudo nmap 10.129.2.28 --top-ports=10

**상위 100개**
-F 옵션

**모든포트**
-p- 옵션

***

**SYN Scan**
\$ sudo nmap 10.129.2.28 -p 21 --packet-trace -Pn -n --disable-arp-ping

| 옵션                 | 제거되는 것             | 목적           |
| ------------------ | ------------------ | ------------ |
| -Pn                | ICMP Echo requests | 바로 SYN 전송    |
| -n                 | DNS 조회             | 트래픽 노이즈 제거   |
| --disable-arp-ping | ARP Discovery      | 순수 SYN 패킷 관찰 |

\[스캔결과]
SENT SYN
RCVD SYN-ACK   → Open
RCVD RST       → Closed
RCVD nothing   → Filtered

***

**TCP Connect Scan**
\$ sudo nmap 10.129.2.28 -p 443 --packet-trace --disable-arp-ping -Pn -n --reason -sT

\[스캔결과]
CONN → Open

***

## Discovering Open UDP Ports / open된 UDP 포트 찾기

UDP Scan(-sU)
UDP는 응답이 X → open|filter
설정되어 응답이 O → open
RCVD - ICMP - unreachable (type=3) → closed

$sudo nmap 10.129.2.28 -F -sU$ sudo nmap 10.129.2.28 -sU -Pn -n --disable-arp-ping --packet-trace -p 137 --reason
